Scope: Reaction wheel sizing for the spiral-outward assembly (one commit)

The spiral-outward assembly needs wheels that store up to 7.33 N m s and deliver up to 17.99 N m. The 20 tests pass. The extra checks I ran here also pass. The result holds only for the ideal, isolated model, and no hardware was checked.

What the code does

While the robot, gantry and tiles move, the whole assembly has zero total angular momentum. If nothing absorbs the robot's internal momentum, the structure turns. Reaction wheels fixed to the structure can absorb it. Then the structure stays still. This change adds the sizing code.

  • The wheels must store hw=−hrelh_w = -h_{rel}hw​=−hrel​.
  • The motors must apply τ=−h˙rel\tau = -\dot h_{rel}τ=−h˙rel​.
  • hrelh_{rel}hrel​ is the internal momentum of the moving parts, seen in the structure frame.
  • The robot ends at rest, so hrelh_{rel}hrel​ returns to zero. The wheels stop, and no momentum dumping is needed in this model.

Module docstring states the momentum balance and the wheel equations.

h_w(t) = -h_rel(t)

How the sizing works

The pipeline has three code steps after the momentum table. build_table samples the scenario every 0.01 s and keeps every phase cut. It uses exact analytic rates, not finite differences, so a coarse sample cannot hide the peak torque. requirement takes the peaks. design_wheel turns a peak into a wheel.

The design rule is: design momentum =m⋅Hreq= m \cdot H_{req}=m⋅Hreq​, design torque =m⋅τreq= m \cdot \tau_{req}=m⋅τreq​, wheel inertia =Hdesign/Ωmax= H_{design}/\Omega_{max}=Hdesign​/Ωmax​, and mass =I/(kr2)= I/(k r^2)=I/(kr2). Here mmm is the margin and must be at least 1.

"""Reaction-wheel sizing for holding structure attitude during assembly (ZO-25).

Physics (same frame and identity as momentum_core / doc-3)
-----------------------------------------------------------
B is the structure frame. The robot, gantry and tiles move relative to B with
a prescribed motion. Their *internal* (relative) angular momentum about the
system centre of mass, expressed in B, is ``h_rel(t)`` (momentum_core
``MassProperties.relative_momentum_B``). With no external torque and zero
initial momentum, the total angular momentum stays zero:

    J(t) @ omega + h_rel(t) + h_w = 0                         (1)

``J`` is the locked inertia of the whole system about its centre of mass,
``omega`` is the structure angular velocity and ``h_w`` is the momentum stored
in reaction wheels that are fixed in B (one wheel per body axis). Without a
wheel, omega = -J^-1 h_rel and the structure turns. To hold omega = 0 exactly,
the wheels must store

    h_w(t) = -h_rel(t)                                         (2)

and the wheel motors must apply (wheel axes are fixed in B, so B components of
h_w change only through motor torque)

    tau_motor(t) = dh_w/dt = -dh_rel/dt.                       (3)

The reaction torque on the structure is -tau_motor. Because h_rel returns to
zero when the robot stops, the wheels end at zero speed: no momentum dumping
is needed in this isolated model.

Assumptions (state them with any number from this module)
- Rigid, isolated, prescribed-motion model; no gravity gradient, drag or
  external torque. Physical hardware feasibility is not checked.
- The wheel mass and inertia are not added to J and do not move the CoM. The
  wheel is small next to the 50 kg structure; the notebooks show the size of
  this error.
- Three orthogonal wheels aligned with B. Other layouts (pyramid, 4-wheel)
  are not modelled.

    """Internal-momentum history on a dense grid, in body frame B.

    def interp(self, t: float):
        """Linear interpolation of (h_rel, h_rel_dot, J) at time t (clamped)."""
        t = float(np.clip(t, self.time[0], self.time[-1]))
        k = int(np.clip(np.searchsorted(self.time, t) - 1, 0, len(self.time) - 2))
        t0, t1 = self.time[k], self.time[k + 1]
        a = 0.0 if t1 == t0 else (t - t0) / (t1 - t0)
        lerp = lambda x: (1 - a) * x[k] + a * x[k + 1]
        return lerp(self.h_rel), lerp(self.h_rel_dot), lerp(self.inertia)

                      wheels: bool = True, dt: float | None = None) -> ControlledRun:
    """Integrate equation (1) with wheel control on the table grid.

    Wheel momentum h_w is the state. omega is algebraic: omega = -J^-1 (h_rel + h_w).
    Motor command  u = -feedforward * dh_rel/dt + J (kp * e + kd * omega),
    with e the attitude error rotation vector (B frame, small-angle PD). Torque
    and momentum limits saturate per axis. wheels=False gives the passive
    (no-wheel) structure motion. Fixed-step RK2 (midpoint) on the table grid,
    or on a uniform grid of step dt.
    """
    t = table.time if dt is None else np.arange(table.time[0], table.time[-1] + dt / 2, dt)
    n = len(t)
    tl = None if torque_limit is None else np.broadcast_to(np.asarray(torque_limit, float), (3,))
    hl = None if momentum_limit is None else np.broadcast_to(np.asarray(momentum_limit, float), (3,))
    q = np.empty((n, 4)); w = np.empty((n, 3)); hw = np.zeros((n, 3)); tau = np.zeros((n, 3))
    q[0] = (0, 0, 0, 1)

    def rates(tk, qk, hwk):
        h, hd, J = table.interp(tk)
        if not wheels:
            return -np.linalg.solve(J, h), np.zeros(3)
        omega = -np.linalg.solve(J, h + hwk)
        e = Rotation.from_quat(qk).as_rotvec()          # B->I rotation; hold identity
        e_B = Rotation.from_quat(qk).inv().apply(e)
        u = -feedforward * hd + J @ (kp * e_B + kd * omega)
        if tl is not None:
            u = np.clip(u, -tl, tl)
        if hl is not None:                               # no torque further into saturation
            u = np.where((np.abs(hwk) >= hl) & (np.sign(u) == np.sign(hwk)), 0.0, u)
        return omega, u

    def qstep(qk, omega, h):
        return (Rotation.from_quat(qk) * Rotation.from_rotvec(omega * h)).as_quat()

    for k in range(n - 1):
        h = t[k + 1] - t[k]
        w0, u0 = rates(t[k], q[k], hw[k])
        w[k], tau[k] = w0, u0
        qm = qstep(q[k], w0, h / 2)
        hm = hw[k] + u0 * h / 2
        if hl is not None:
            hm = np.clip(hm, -hl, hl)
        wm, um = rates(t[k] + h / 2, qm, hm)
        q[k + 1] = qstep(q[k], wm, h)
        hw[k + 1] = hw[k] + um * h
        if hl is not None:
            hw[k + 1] = np.clip(hw[k + 1], -hl, hl)
    w[-1], tau[-1] = rates(t[-1], q[-1], hw[-1])
    err = np.degrees(Rotation.from_quat(q).magnitude())
    return ControlledRun(t, q, w, hw, tau, err)


def wheel_inertia_error(design_mass_kg: float, offset_m: float, inertia_min_kgm2: float) -> float:
    """Fractional change of the smallest system inertia if a wheel of this mass
    sits offset_m from the CoM (parallel-axis upper estimate of the neglected term)."""
    return design_mass_kg * offset_m**2 / inertia_min_kgm2

@dataclass(frozen=True)
class WheelRequirement:
    """What the wheels must do to hold omega = 0 (equations 2 and 3)."""
    peak_momentum_axis_Nms: tuple      # max |h_w| per body axis x, y, z
    peak_momentum_norm_Nms: float      # max |h_w| (vector)
    t_peak_momentum_s: float
    peak_torque_axis_Nm: tuple         # max |tau| per axis
    peak_torque_norm_Nm: float
    t_peak_torque_s: float
    final_momentum_Nms: tuple          # should be ~0: no dumping needed
    sample_dt_max_s: float

    def as_dict(self):
        return asdict(self)


def requirement(table: MomentumTable) -> WheelRequirement:
    hw = -table.h_rel
    tau = -table.h_rel_dot
    hn, tn = np.linalg.norm(hw, axis=1), np.linalg.norm(tau, axis=1)
    return WheelRequirement(
        tuple(float(x) for x in np.abs(hw).max(0)), float(hn.max()), float(table.time[hn.argmax()]),
        tuple(float(x) for x in np.abs(tau).max(0)), float(tn.max()), float(table.time[tn.argmax()]),
        tuple(float(x) for x in hw[-1]), float(np.diff(table.time).max()))


def requirement_from_history(path: str | Path = RETAINED_HISTORY) -> dict:
    """ZO-23 method: h = J omega from a saved history, torque by np.gradient.

    Gives a *sampled* torque, which is a lower bound on the true peak.
    """
    d = np.load(path)
    t, J, w = d["time"], d["inertia_B"], d["omega_B"]
    h = np.einsum("tij,tj->ti", J, w)       # = -h_rel = wheel momentum needed
    dh = np.gradient(h, t, axis=0)
    return {"peak_momentum_norm_Nms": float(np.linalg.norm(h, axis=1).max()),
            "peak_torque_norm_Nm_sampled": float(np.linalg.norm(dh, axis=1).max()),
            "peak_momentum_axis_Nms": tuple(float(x) for x in np.abs(h).max(0)),
            "peak_torque_axis_Nm_sampled": tuple(float(x) for x in np.abs(dh).max(0)),
            "time": t, "wheel_momentum": h, "q_IB": d["q_IB"]}

@dataclass(frozen=True)
class WheelDesign:
    """One wheel. Rim model: I = k * m * r^2 (k = 1 thin rim, 0.5 solid disc)."""
    axis: str
    required_momentum_Nms: float
    required_torque_Nm: float
    margin: float
    max_speed_rpm: float
    design_momentum_Nms: float
    inertia_kgm2: float
    design_torque_Nm: float
    radius_m: float
    shape_factor: float
    mass_kg: float
    peak_power_W: float               # design torque * max speed (motor sizing bound)

    def as_dict(self):
        return asdict(self)


def design_wheel(required_momentum: float, required_torque: float, *, axis: str = "z",
                 margin: float = 1.5, max_speed_rpm: float = 6000.0, radius_m: float = 0.10,
                 shape_factor: float = 1.0) -> WheelDesign:
    """Size one wheel from momentum and torque needs.

    H_design = margin * H_req;  I_w = H_design / Omega_max;
    tau_design = margin * tau_req;  m = I_w / (k r^2);  P = tau_design * Omega_max.
    """
    if margin < 1 or max_speed_rpm <= 0 or radius_m <= 0 or not 0 < shape_factor <= 1:
        raise ValueError("need margin >= 1, positive speed and radius, 0 < shape_factor <= 1")
    omega = max_speed_rpm * RPM
    H = margin * required_momentum
    I = H / omega
    tau = margin * required_torque
    return WheelDesign(axis, required_momentum, required_torque, margin, max_speed_rpm, H, I, tau,
                       radius_m, shape_factor, I / (shape_factor * radius_m**2), tau * omega)
