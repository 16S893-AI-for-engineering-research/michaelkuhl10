What it is
A free, open tool for a literature review that lasts. It joins a spreadsheet workbook, a Zotero library and short paper cards. Every claim on a card has a page number and an exact quote, and the tool checks each quote against the PDF.

Who it is for
Anyone in the lab. You set your own topics, stages and research context in one config file. A 5-minute quick start uses a built-in synthetic example, so you need no Zotero account to try it.

How to start
1. git clone https://github.com/michaelkuhl10/lit-review-toolkit
2. python3 -m pip install -r requirements.txt
3. python3 -m litkit init
4. Follow docs/ZOTERO_SETUP.md to connect Zotero (about 15 minutes).
